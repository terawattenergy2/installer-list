# ช่างใกล้คุณ
เว็บรายชื่อผู้ให้บริการติดตั้ง ภาษาไทย ออกแบบสำหรับมือถือ ใช้ HTML, CSS, JavaScript ปกติ ไม่มี framework และไม่มีขั้นตอน build

## นำขึ้น Vercel
1. นำไฟล์ในโฟลเดอร์นี้ขึ้น GitHub repository
2. ใน Vercel เลือก Add New → Project แล้วเลือก repository
3. Framework Preset: Other
4. Root Directory: โฟลเดอร์ที่มี index.html (ถ้าวางไฟล์ไว้บนสุด ใช้ค่าเริ่มต้น)
5. Build Command: เว้นว่าง และ Output Directory: .
6. กด Deploy

หรือใช้ Vercel CLI ภายในโฟลเดอร์นี้: `vercel --prod`

เปิด index.html ในเบราว์เซอร์ได้ทันทีสำหรับการทดลองแบบออฟไลน์

## ไฟล์
- index.html: หน้าเว็บ
- style.css: รูปแบบ responsive
- app.js: ค้นหา กรอง เรียงลำดับ แสดงเพิ่มเติม และเก็บตัวกรองใน URL
- data.js: รายชื่อ 665 รายจากไฟล์แนบ รวมรายการที่มี hidden ใน HTML ต้นทาง
- vercel.json: ตั้งค่าพื้นฐาน Vercel

ค้นหาชื่อบริษัท ผู้ติดต่อ จังหวัด ที่อยู่ เบอร์โทร อีเมล และเลขทะเบียนได้ ตัวกรองแบ่งจังหวัด ประเภทนิติบุคคลตามชื่อ และช่องทางติดต่อ ข้อมูลต้นฉบับไม่ได้ระบุประเภทงานติดตั้ง จึงไม่ได้คาดเดาหรือจัดประเภทงานเพิ่มเติม

เบอร์โทรใช้ลิงก์ tel: มือถือจะเปิดแอปโทรศัพท์ให้ยืนยันการโทร ส่วนอีเมลใช้ mailto: ข้อมูลแสดงตามต้นทาง ไม่ได้ตรวจสอบความเป็นปัจจุบันกับผู้ให้บริการ

หากเผยแพร่ Vercel แบบสาธารณะ ผู้เข้าชมจะสามารถอ่านรายชื่อและข้อมูลติดต่อทั้งหมดใน data.js ได้
