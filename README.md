# ช่างใกล้คุณ — MEA + PEA

เว็บค้นหาผู้ให้บริการโซลาร์เซลล์ ใช้ HTML, CSS และ JavaScript เปิด index.html ได้โดยไม่ต้องติดตั้งหรือ build

## ข้อมูลรวม: PEA ณ 20 พฤศจิกายน 2569 / MEA ณ 28 ตุลาคม 2569

- MEA: 665 รายการจากไฟล์แนบของผู้ใช้ เป็น 653 บริษัทเมื่อรวมเลขผู้เสียภาษีซ้ำ
- PEA: 711 บริษัทจาก https://peoplesolar.pea.co.th/vendors?province และ API ที่หน้าเว็บเรียกใช้ https://peoplesolar.pea.co.th/api/backend/v1/vendors
- บริษัทที่อยู่ทั้งสองแหล่ง 384 บริษัท รวมเป็น 980 บริษัทไม่ซ้ำ
- เก็บข้อมูลต้นทางครบ 1,376 รายการใน sourceRecords รวมเลขทะเบียน ชื่อ ที่อยู่ ผู้ติดต่อ เบอร์โทรและอีเมล ไม่ทิ้งรายการซ้ำ

## ขอบเขตพื้นที่

MEA ใช้สำหรับกรุงเทพมหานคร นนทบุรี และสมุทรปราการ ตามขอบเขตชุดข้อมูลที่ผู้ใช้ระบุ ผู้ให้บริการในชุด MEA ใช้ค้นหาในทั้งสามจังหวัดนี้ ไม่ได้อนุมานจากที่อยู่บริษัท และไม่ได้มีข้อมูลยืนยันพื้นที่รายบริษัทแยกย่อยกว่านี้

PEA ใช้เฉพาะอีก 74 จังหวัด อ้างอิงรายชื่อจังหวัดที่รับงานในฟิลด์ provinces ของแต่ละบริษัท ตัดสามจังหวัดในพื้นที่ MEA ออกจากพื้นที่บริการฝั่ง PEA ตามที่ผู้ใช้กำหนด

province คือจังหวัดที่จดทะเบียน ส่วน serviceAreas คือพื้นที่ให้บริการที่ใช้กรอง การเลือกจังหวัดร่วมกับแหล่งข้อมูลใช้เงื่อนไขทั้งสองพร้อมกัน และแสดงข้อมูลติดต่อจากแหล่งที่ตรงกับพื้นที่นั้น

รวมรายการด้วยเลขผู้เสียภาษี 13 หลัก ไม่รวมจากชื่อคล้ายกันหรือเลขผู้ให้บริการ เพราะเลขทะเบียน MEA และ PEA เป็นคนละชุด เก็บรายการจากทั้งสองแหล่งใน sourceRecords เพื่อดูย้อนหลังได้ ค่าว่างคือข้อมูลต้นทางไม่ได้ระบุ ไม่รวมบัตร PEA Solar ที่เว็บ PEA แสดงแยกจากรายชื่อ

## ไฟล์และการใช้งาน

- index.html: หน้าเว็บ
- style.css: รูปแบบเดิมพร้อมป้าย MEA / PEA และการปรับสำหรับมือถือ
- app.js: ค้นหา กรองจังหวัดพื้นที่บริการ แหล่งข้อมูล ประเภทนิติบุคคล ช่องทางติดต่อ เรียงลำดับ ดูเพิ่มเติม และเก็บตัวกรองใน URL
- data.js: ข้อมูลรวมสำหรับเว็บที่เปิดแบบออฟไลน์
- vendors.json: ข้อมูลรวมสำหรับนำไปใช้ต่อใน React หรือระบบอื่น
- vercel.json: การตั้งค่าเว็บ static ตามโครงการเดิม

เปิด index.html เพื่อใช้งาน ข้อมูลในเว็บเป็นชุดข้อมูลที่บันทึกไว้ ไม่อัปเดตจากต้นทางอัตโนมัติ

## ตรวจสอบ

ตรวจจำนวนผู้ให้บริการทั้ง 77 จังหวัดเทียบกับต้นทาง MEA และ PEA ตรวจขอบเขตพื้นที่ การรวมรายการซ้ำ การเก็บรายการต้นฉบับ การค้นหา ตัวกรองช่องทางติดต่อ การแสดงเพิ่มเติม สถานะไม่พบข้อมูล และตัวกรองจาก URL ด้วยการรัน JavaScript ของเว็บในสภาพแวดล้อมทดสอบ DOM จำลอง ผ่านทั้งหมด

ยังไม่ได้ตรวจภาพหน้าจอในเบราว์เซอร์ เนื่องจากนโยบายเบราว์เซอร์ของเครื่องมือบล็อก file://

## นำขึ้น Vercel

ใช้ Framework Preset: Other, ไม่ต้องมี Build Command และ Output Directory: . ตามโครงการเดิม ยังไม่ได้เผยแพร่หรือ deploy ในงานนี้

## จำนวนผู้สนใจจาก PEA

อัปเดต PEA วันที่ 20 พฤศจิกายน 2569 จาก https://peoplesolar.pea.co.th/vendors?sort=selections&order=desc ครบ 711 ราย เทียบชุดเดิมมี ID ใหม่ 28 รายและ ID เดิมไม่อยู่ในผลล่าสุด 12 ราย ข้อมูล MEA คงชุดเดิม

แสดง selectionCount จาก PEA ต่อบริษัท เรียงผู้สนใจมากไปน้อยได้ และส่งออกเป็นคอลัมน์ตัวเลขใน Excel ยอดนี้เป็นยอดรวมต่อบริษัท ไม่ใช่ยอดแยกจังหวัด และไม่ควรตีความผลรวมเป็นจำนวนบุคคลไม่ซ้ำ หน้าเว็บสาธารณะ/API ที่ใช้ไม่มีรายชื่อบุคคลผู้สนใจ ชุด MEA ไม่มีฟิลด์นี้ จึงแสดงเป็นค่าว่างแทนศูนย์

Export Excel ส่งออกทุกรายการที่ตรงกับตัวกรอง รวมรายการที่ยังไม่กดแสดงเพิ่มเติม พร้อมเงื่อนไขและวันที่ข้อมูล PEA/MEA แยกกัน

## ปุ่มอัปเดต PEA / MEA ตามสั่ง

เลือก PEA, MEA หรือทั้งคู่แล้วกดอัปเดตข้อมูล ระบบจึงเรียก /api/update-directory แบบ POST ไม่มีการตั้งเวลา ไม่มีการดึงตอนเปิดหน้า และไม่มีการอัปเดตพื้นหลัง

ข้อมูลที่ได้เก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น และใช้ค้นหา กรอง และ Export Excel ได้ทันที เปิดหน้าใหม่ยังใช้ข้อมูลที่เก็บไว้ การอัปเดตนี้ไม่ได้เขียนกลับ GitHub หรือเปลี่ยนข้อมูลของผู้ใช้คนอื่น วันที่ข้อมูลแต่ละแหล่งแสดงในแผงอัปเดต

ถ้าเลือกทั้งคู่ ต้องโหลดสำเร็จครบทุกหน้าจากทั้งสองแหล่งก่อนแทนที่ชุดเดิม ตรวจจำนวนกับต้นทางและรหัสซ้ำ ถ้าข้อมูลไม่ครบ ต้นทางล่ม หรือบันทึกไม่ได้ จะคงข้อมูลเดิมไว้ MEA ใช้ snapshot เดียวกันทุกหน้าเพื่อรักษาลำดับข้อมูล

แหล่ง MEA: https://peoplesolar.mea.or.th/vendor; แหล่ง PEA: https://peoplesolar.pea.co.th/api/backend/v1/vendors จำกัดต้นทางไว้ในโค้ด ไม่รับ URL จากผู้เรียก API

manual-update.js ดูแลการดึงและรวมข้อมูล ส่วน api/update-directory.js เป็น Vercel Node function ต้องใช้งานผ่าน Vercel เพื่ออัปเดตจากต้นทาง การเปิด HTML ออฟไลน์ยังค้นหาและส่งออกชุดข้อมูลเดิมได้ แต่ปุ่มอัปเดตต้องเชื่อมต่อเว็บ
